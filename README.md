# 🐍 100 Days of Code: The Python Challenge

Welcome to my **100 Days of Code** challenge repository! This project serves as a daily log of my journey to master Python, build real-world applications, and develop strong programmatic thinking.

## 🚀 The Challenge Rules
Inspired by the official [#100DaysOfCode](https://www.100daysofcode.com/) movement, I commit to:
1. Code for at least **one hour every day** for the next 100 days.
2. Document my progress here and share daily updates on social media.

---

## 🗺️ Curriculum Overview

| Phase | Days | Focus Areas | Key Milestones |
| :--- | :--- | :--- | :--- |
| 🟢 **Beginner** | Days 1-14 | Python fundamentals, data types, logic, and loops | Band Name Generator, Blackjack, Higher-Lower |
| 🔵 **Intermediate** | Days 15-30 | OOP, local IDE setup, Turtle graphics, GUI (Tkinter), and files | Snake Game, Pong, Password Manager |
| 🟡 **Intermediate+**| Days 31-58 | APIs, Web Scraping, Web Dev (Flask), and Automation | Amazon Tracker, Automated Birthday Wisher |
| 🏆 **Advanced** | Days 59-100 | Data Science (Pandas, NumPy), Web Apps, and Capstones | Custom Blog, Portfolio Projects |

## 📅 Daily Progress Log

*(Note: The full detailed daily breakdown from Day 1 through Day 100, including specific mini-projects for each day, can be found in the referenced repository. Below is a summarized structure of the phases).*

- **Phase 1: Beginner Fundamentals (Days 1-14)** - Covers variables, data types, control flow, loops, functions, and debugging with projects like Band Name Generator and Blackjack.
- **Phase 2: Intermediate & GUIs (Days 15-30)** - Covers OOP, Turtle graphics, CSV/Pandas, and Tkinter GUI applications like the Snake Game and Password Manager.
- **Phase 3: Intermediate+ Web, APIs, & Automation (Days 31-58)** - Covers APIs, web scraping with Beautiful Soup, automation with Selenium, and web development using Flask.
- **Phase 4: Advanced Web Developer & Data Science (Days 59-100)** - Focuses on advanced Flask apps, databases (SQLite/SQLAlchemy), and capstone portfolio projects.

## 🛠️ How to Run the Projects Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the specific day's directory:
   ```bash
   cd Day-XX
   ```
3. Run the script:
   ```bash
   python main.py
   ```
